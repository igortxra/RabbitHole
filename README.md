# Rabbit Hole
This repository is just an RabbitMQ study case based on [RabbitMQ Tutorials](https://www.rabbitmq.com/tutorials) using **Python**.

I didn't do exactly the same examples of this tutorial (mainly avoiding the terminal input interactions because I used docker containers and wanted to keep it simple), but the result is the same.
